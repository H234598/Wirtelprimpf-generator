# Web-Zustand

Der vollständige, versionierte und datensparsame Storagevertrag steht in
[`WEB-LOCAL-STATE.md`](WEB-LOCAL-STATE.md). Dieses Dokument ist der
planseitige Alias für Lesefortschritt, Favoriten, Migration, Löschung,
No-JS-Verhalten und Storage-Ausfall.

Die Komfortfunktionen speichern ausschließlich stabile Kapitel-/Asset-IDs
und begrenzte Positionen. Sie sind nicht kanonisch: URL, Kapitelroute und
statische Links funktionieren ohne JavaScript und ohne verfügbaren Storage.
